# ریری بیوتی | فروشگاه لوازم آرایشی

فروشگاه آنلاین لوازم آرایشی و بهداشتی ساخته‌شده با React، TypeScript و Tailwind CSS. رابط کاربری دوزبانه است: فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست) با امکان تغییر زبان از هدر سایت.

## امکانات

- رابط کاربری دوزبانه (فارسی / English) با تغییر خودکار جهت صفحه (RTL/LTR) و ذخیره زبان انتخابی در مرورگر
- کاتالوگ محصولات با جستجو (به هر دو زبان)، فیلتر دسته‌بندی، بازه قیمت و مرتب‌سازی
- صفحه جزئیات محصول با انتخاب رنگ و تعداد
- سبد خرید و فرایند تکمیل خرید (بدون اتصال به درگاه پرداخت واقعی)
- ورود / ثبت‌نام و پنل کاربری با تاریخچه سفارش‌ها
- لیست علاقه‌مندی‌ها
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

داده محصولات و کاربران در حال حاضر به‌صورت نمونه (mock) و در حافظه مرورگر (localStorage) مدیریت می‌شود و ساختار آن برای اتصال به یک بک‌اند واقعی آماده است (به‌ویژه `src/store` و `src/data`).

## پنل مدیریت

پوشه [`admin-dashboard`](admin-dashboard) یک پروژه جداگانه است: داشبورد مدیریتی فارسی با Vue 3، Pinia و Tailwind CSS. راهنمای آن در [`admin-dashboard/README.md`](admin-dashboard/README.md) است.

## اجرا

```bash
npm install
npm run dev
```

## دستورات

- `npm run dev` — اجرای سرور توسعه
- `npm run build` — بیلد نسخه تولید
- `npm run lint` — بررسی کد با Oxlint
- `npm run preview` — پیش‌نمایش نسخه بیلد شده

## ساختار پروژه

```
src/
  components/   کامپوننت‌های مشترک (Header، Footer، ProductCard، ...)
  data/         داده نمونه محصولات و دسته‌بندی‌ها (دوزبانه)
  i18n/         سیستم چندزبانگی (دیکشنری ترجمه‌ها و Context زبان)
  layouts/      قالب اصلی صفحات
  pages/        صفحات اصلی سایت
  store/        مدیریت state با Zustand (سبد خرید، احراز هویت، علاقه‌مندی‌ها)
  types/        تایپ‌های TypeScript
  utils/        توابع کمکی (قالب‌بندی قیمت و تاریخ)
```
