# پنل مدیریت ریری

داشبورد مدیریتی فارسی و راست‌به‌چپ ساخته‌شده با **Vue 3** (Composition API و `<script setup>`)، **Vite**، **Vue Router**، **Pinia** و **Tailwind CSS 4**. بک‌اند ندارد و داده‌ها را از فایل‌های JSON می‌خواند.

## اجرا

```bash
cd admin-dashboard
npm install
npm run dev      # سرور توسعه
npm run build    # بیلد تولید در پوشه dist
npm run preview  # پیش‌نمایش بیلد
```

حساب آزمایشی: `admin@example.com` / `admin123` (در صفحه ورود دکمه «پر کردن خودکار» هم هست).

## صفحات

| مسیر | توضیح |
|---|---|
| `/login` | ورود با اعتبارسنجی، نمایش/پنهان کردن رمز و «مرا به خاطر بسپار» |
| `/` | داشبورد: کارت‌های آماری، نمودار درآمد ماهانه (۶ یا ۱۲ ماه، با tooltip و پشتیبانی کیبورد) و آخرین تراکنش‌ها |
| `/users` | لیست کاربران با جستجو، فیلتر نقش و وضعیت، مرتب‌سازی، صفحه‌بندی و حذف با تأیید |
| `/users/new` و `/users/:id/edit` | فرم افزودن/ویرایش کاربر با اعتبارسنجی |

## امکانات

- کاملاً RTL با فونت وزیرمتن، ارقام فارسی و تاریخ شمسی (از طریق `Intl` و بدون کتابخانه اضافه)
- واکنش‌گرا: سایدبار کشویی در موبایل/تبلت، جدول‌ها در موبایل به کارت تبدیل می‌شوند
- تم روشن/تاریک (پیش‌فرض بر اساس تنظیم سیستم، ذخیره در مرورگر، بدون چشمک هنگام بارگذاری)
- محافظت از مسیرها با Router Guard و بازگشت به صفحه درخواستی بعد از ورود
- فیلترهای لیست کاربران در آدرس صفحه ذخیره می‌شوند (با بازگشت از ویرایش از دست نمی‌روند)
- اعتبارسنجی فرم: فیلدهای الزامی، حروف فارسی، ایمیل معتبر و تکراری نبودن آن، موبایل ایران (ارقام فارسی هم پذیرفته می‌شود)
- اعلان‌های toast و پنجره تأیید حذف

## داده‌ها

فایل‌های `src/data/*.json` منبع داده‌اند و فقط از طریق `src/services/api.js` خوانده می‌شوند (با تأخیر شبیه‌سازی‌شده شبکه). تغییرات کاربران (افزودن، ویرایش، حذف) در `localStorage` ذخیره می‌شود؛ دکمه «بازنشانی داده‌ها» در صفحه کاربران همه چیز را به حالت JSON اولیه برمی‌گرداند. برای اتصال به API واقعی کافی است توابع `api.js` با `fetch` جایگزین شوند.

## ساختار پروژه

```
src/
  components/
    ui/          کامپوننت‌های پایه: آیکون، Badge، فیلد فرم، صفحه‌بندی، دیالوگ، Toast، تغییر تم
    layout/      سایدبار و هدر
    dashboard/   کارت آمار، نمودار درآمد، جدول تراکنش‌ها
    users/       فیلترها، جدول و فرم کاربر
  composables/   useForm — مدیریت فرم و اعتبارسنجی
  data/          فایل‌های JSON
  layouts/       قالب اصلی پنل (سایدبار + هدر)
  router/        مسیرها و Guard احراز هویت
  services/      لایه دسترسی به داده
  stores/        Pinia: auth، users، theme، toast
  utils/         قالب‌بندی اعداد و تاریخ، قوانین اعتبارسنجی، ثابت‌ها
  views/         صفحات
```
